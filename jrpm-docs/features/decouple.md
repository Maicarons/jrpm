# 机车换挂（decouple）

> 来源：pulsexlb/OpenTTD-patches 的 `jgrpp-decouple` 特性分支（152 提交中的核心），经 git merge 并入 jrpm。

## 功能简介

「机车换挂」让列车能够在站内/调度中**解挂与挂载**车厢或机车，实现：

- **解挂**：列车按「解挂订单」在指定站点甩下部分车厢（或车厢+机车组），剩余部分继续行驶；
- **挂载**：列车在站点等待，与另一列（或停泊的车厢组）自动对接耦合；
- **解挂后两列车各自独立执行调度**：通过「条件性命令跳过」等机制，解挂后的两列车执行不同的调度计划；
- **路签转移**：解挂/挂载时路签（追踪限制标签）随列车正确转移或去重。

## 核心能力

| 能力 | 说明 |
|---|---|
| 解挂/挂载订单 | 新增订单类型，支持「加载/不加载」「等待挂载」「解挂」等约束 |
| 耦合长度与车速限制 | 根据列车长度限制耦合操作；耦合操作有速度限制 |
| 双车头支持 | 前后双车头（含 NewGRF 双头机车）正确耦合/解挂 |
| 耦合寻路 | YAPF/NPF 均支持耦合路径规划；只在站内耦合 |
| 反向行驶 | 耦合后可反向，支持「解挂后反向」等调度技巧 |
| NewGRF 耦合 | 支持 NewGRF 定义的耦合属性（0xC6/0xF2 属性等） |
| 存档 | `SLV_ORDER_DECOUPLE` 存档版本；`num_decouple` 计数持久化 |

## 使用方式

1. 在车站用「解挂」订单（`decouple`）拆分列车；
2. 设置挂载订单让列车等待对接；
3. 配合「条件性命令跳过」（conditional order skip）让解挂后的两列车走不同路线；
4. 站内拖拽调整车厢顺序，或使用「按长度筛选」等辅助工具。
