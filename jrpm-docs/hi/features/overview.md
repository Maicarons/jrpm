# सुविधाएँ अवलोकन

jrpm = jgrpp की सभी विशेषताएँ + pulsexlb (लोकोमोटिव डीकपलिंग + मॉड्यूलर एयरपोर्ट) + modded (यात्रा इतिहास + टैक्सी गति) + cmclient से उधार (मल्टीप्लेयर UI संवर्द्धन) + jrpm-विशिष्ट सुविधाएँ।

| # | सुविधा | दस्तावेज़ | स्थिति |

| 2 | सर्वर सीमा अनुसंधान | [सर्वर सीमा अनुसंधान](./02-server-caps) | 📖 अनुसंधान निष्कर्ष (संरचनात्मक सीमाएँ) |
| 3 | स्वचालित वाहन समूहीकरण | [स्वचालित वाहन समूहीकरण](./03-vehicle-autogroup) | ✅ कार्यान्वित |

## पूर्ण रूप से विरासत में मिला

- **jgrpp की सभी विशेषताएँ**: सिग्नल संवर्द्धन (मल्टीपल सिग्नल/प्रोग्रामेबल सिग्नल/स्लॉट और काउंटर), शेड्यूल्ड डिस्पैच, ट्रेसरेस्ट्रिक्ट, टेम्पलेट प्रतिस्थापन, लोको/वैगन पृथक्करण खरीद विंडो, यथार्थवादी ब्रेकिंग, वन-वे रोड संवर्द्धन, लेवल क्रॉसिंग सुरक्षा आदि;
- **OpenTTD 16.0 कर्नेल**: NewGRF/स्क्रिप्ट/सेव पारिस्थितिकी तंत्र के साथ पूर्ण संगतता।
