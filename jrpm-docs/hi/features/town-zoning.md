# टाउन ज़ोनिंग

cmclient टाउन ज़ोनिंग पोर्ट (चौथा बैच, कमिट `9e3f95a2`)। jrpm बेस (pulsexlb) में पहले से ही एक ज़ोनिंग सिस्टम है (टूलबार + ड्रॉइंग पाइपलाइन + मेनू), इस बैच ने इसके ऊपर cmclient के अद्वितीय मूल्यांकन मोड और **growth_tiles सेव** को जोड़ा।

## नए मोड (ज़ोनिंग टूलबार ड्रॉपडाउन)

| मोड | विवरण | रंग |
|---|---|---|
| **Town zones (Tz)** | शहर संकेंद्रित क्षेत्र, `squared_town_zone_radius` का पुन: उपयोग करता है | Tz0 किनारा=हल्का नीला / Tz1=लाल / Tz2=पीला / Tz3=हरा / Tz4 शहर केंद्र=सफ़ेद |
| **Town growth tiles** | चालू/पिछले महीने के मकान निर्माण और विध्वंस ट्रैक | नया मकान=हरा / विध्वंस=हल्का नीला / पुनर्निर्माण=सफ़ेद / वृद्धि छोड़ें=नारंगी / निर्माण छोड़ें=पीला / सर्वर विध्वंस=लाल |

## growth_tiles डेटा लेयर (`cm_town_growth.cpp/.h`)

- दो रोलिंग माह मैप: `TileIndex → TownGrowthTileState` (चालू माह / पिछला माह)
- ईवेंट हुक:
  - `BuildTownHouse` → `NEW_HOUSE` (यदि पिछले माह विध्वंस था तो `RH_REBUILT` में अपग्रेड)
  - `ClearTownHouse` → `RH_REMOVED`
  - `TownsMonthlyLoop` → मासिक रोटेशन (पिछला माह = चालू माह, चालू माह खाली)
- **सेव स्थायित्व**: नया `GRWT` सेवगेम चंक (`misc_sl.cpp`), `{tile, state}` जोड़ी सूची के रूप में सीरियलाइज़; पुराने सेव में यह चंक नहीं है, लोडिंग पूरी तरह संगत (सेव→लोड राउंडट्रिप सत्यापित)।

## खोलने का तरीका

टूलबार मेनू → मानचित्र (ज़ोनिंग) → ज़ोनिंग टूलबार खोलें, आंतरिक और बाहरी रिंग ड्रॉपडाउन में क्रमशः मूल्यांकन मोड चुनें।

## कटौती स्पष्टीकरण

cmclient के CityBuilder सर्वर-विशिष्ट मोड (CB स्वीकृति क्षेत्र / CB शहर सीमा) और `ext::Town` विस्तारित फ़ील्ड (विज्ञापन, धन, कार्गो सांख्यिकी) सर्वर गेमप्ले-विशिष्ट हैं, पोर्ट नहीं किए गए।
