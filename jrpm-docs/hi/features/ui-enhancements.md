# मल्टीप्लेयर UI संवर्द्धन

दूसरा बैच **citymania-org/cmclient** से पोर्ट किया गया, **कंसोल कमांड** के रूप में कार्यान्वित (cmclient के हॉटकी/टूलबार बुनियादी ढाँचे पर निर्भर नहीं, स्थिर और स्क्रिप्ट करने योग्य)।

## स्थान बुकमार्क (Viewport Locations)

मुख्य व्यूपोर्ट स्थिति और ज़ूम को सहेजें/पुनर्स्थापित करें (9 स्लॉट), मल्टीप्लेयर में अपने कारखानों, स्टेशनों और प्रतिद्वंद्वी क्षेत्रों के बीच त्वरित आवागमन के लिए उपयुक्त।

```
savelocation <1-9>    # वर्तमान व्यूपोर्ट स्थिति+ज़ूम सहेजें
gotolocation <1-9>    # सहेजी गई स्थिति पर जाएँ
```

## कंपनी कार्गो विवरण (Company Cargo Details)

कंपनी द्वारा **वितरित मात्रा + आय** को कार्गो के अनुसार सूचीबद्ध करने वाली सांख्यिकी विंडो, **कुल / पिछला महीना** दो अवधियों के बीच स्विच कर सकती है।

```
company_cargo <company_id>    # कार्गो विवरण विंडो खोलें
```

- विंडो प्रत्येक मानक कार्गो की मात्रा, आय + नीचे कुल सूचीबद्ध करती है (cmclient के बिल्कुल समान)
- हेडर "Cargo" पर क्लिक करके कुल/पिछला महीना अवधि स्विच करें
- प्रति कार्गो आय `CompanyEconomyEntry::cargo_income` के माध्यम से ट्रैक की जाती है (`XSLFI_COMPANY_CARGO_INCOME` सेव विस्तार), सेव आने-जाने में कोई हानि नहीं

## दर्शक सहायता (Watch)

पर्यवेक्षक किसी कंपनी के निर्माण क्षेत्र में त्वरित रूप से पहुँच सकते हैं (उस कंपनी के अंतिम निर्माण के निर्देशांक पर जाएँ)।

```
watch <company_id>    # व्यूपोर्ट कंपनी के स्थान पर जाए
```

## छोड़े गए आइटम और कारण

| cmclient सुविधा | jrpm उपचार |
|---|---|
| खिलाड़ी सूची ओवरले (cm_client_list_gui) | jgrpp में **पहले से** Online Players विंडो है (`NetworkClientList`), दोहराने की आवश्यकता नहीं |
| जमीन विवरण टूलटिप (cm_tooltips) | jrpm का LandInfoWindow **पहले से** मकान/उद्योग/स्टेशन विवरण प्रदर्शित करता है |
