# فك القاطرة (decouple)

> المصدر: فرع الميزات `jgrpp-decouple` من pulsexlb/OpenTTD-patches (أساسي من 152 commit)، تم دمجه في jrpm عبر git merge.

## مقدمة الوظيفة

يتيح "فك القاطرة" للقطارات **فصل وربط** العربات أو القاطرات داخل المحطات/أثناء الجدولة، مما يحقق:

- **الفك**: يقوم القطار بـ "فك" جزء من العربات (أو عربات + مجموعة قاطرات) في محطة محددة وفقاً لـ "أمر فك"، ويستمر الجزء المتبقي في السير؛
- **الربط**: ينتظر القطار في المحطة ليلتقط تلقائياً مع قطار آخر (أو مجموعة عربات متوقفة)؛
- **بعد الفك، يعمل القطاران بشكل مستقل**: من خلال آليات مثل "تخطي الأوامر الشرطية"، ينفذ القطاران بعد الفك خطط جدولة مختلفة؛
- **نقل العلامات**: عند الفك/الربط، يتم نقل العلامات (تسميات تقييد التتبع) بشكل صحيح مع القطار أو إزالة التكرار.

## القدرات الأساسية

| القدرة | الوصف |
|---|---|
| أوامر الفك/الربط | أنواع أوامر جديدة، تدعم قيود مثل "تحميل/لا تحميل" "انتظار الربط" "فك" |
| حدود طول الربط وسرعة القطار | تقييد عملية الربط حسب طول القطار؛ عملية الربط لها حد سرعة |
| دعم قاطرتين | الربط/الفك الصحيح لقاطرتين أمامية وخلفية (بما في ذلك القاطرات مزدوجة الرأس NewGRF) |
| توجيه الربط | يدعم YAPF/NPF تخطيط مسار الربط؛ الربط فقط داخل المحطات |
| السير للخلف | يمكن عكس الاتجاه بعد الربط، يدعم حيل الجدولة مثل "العكس بعد الفك" |
| ربط NewGRF | يدعم خصائص الربط المحددة بواسطة NewGRF (الخصائص 0xC6/0xF2، إلخ) |
| الحفظ | إصدار حفظ `SLV_ORDER_DECOUPLE`؛ استمرار عداد `num_decouple` |

## طريقة الاستخدام

1. استخدم أمر "فك" (`decouple`) في المحطة لتقسيم القطار؛
2. قم بتعيين أمر ربط لانتظار القطار للالتقاط؛
3. استخدم "تخطي الأوامر الشرطية" (conditional order skip) لجعل القطارين بعد الفك يسلكان مسارات مختلفة؛
4. اسحب داخل المحطة لترتيب تسلسل العربات، أو استخدم أدوات مساعدة مثل "التصفية حسب الطول".
