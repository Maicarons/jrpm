# نظرة عامة على الميزات

jrpm = جميع ميزات jgrpp + pulsexlb (فك القاطرة + مطار معياري) + modded (سجل الرحلة + سرعة السير) + استعارة من cmclient (تحسين واجهة المستخدم عبر الشبكة) + وظائف حصرية لـ jrpm.

## الوظائف الحصرية لـ jrpm

| # | الوظيفة | التوثيق | الحالة |
|---|---|---|---|
| 1 | تنزيل الموارد: مرايا متعددة + متوازي | [تنزيل الموارد](./01-resource-download) | ✅ تم التنفيذ (عدد متزامن قابل للتكوين) |
| 2 | بحث حدود الخادم | [بحث حدود الخادم](./02-server-caps) | 📖 استنتاجات بحث (قيود هيكلية) |
| 3 | التجميع التلقائي للمركبات | [التجميع التلقائي للمركبات](./03-vehicle-autogroup) | ✅ تم التنفيذ |
| 4 | ذكاء اصطناعي يدرك اللعبة بأكملها | [ذكاء اصطناعي يدرك اللعبة بأكملها](./05-global-ai) | ✅ تم التنفيذ |

> ملاحظة: تمت إزالة الميزة الأصلية F4 "تلميح سعر البناء" حسب الطلب (commit `96ebfb75`).

## الوراثة الكاملة

- **جميع ميزات jgrpp**: إشارات محسّنة (إشارات متعددة/إشارات قابلة للبرمجة/فتحات وعدادات)، جدولة مجدولة، tracerestrict، استبدال القوالب، نافذة شراء منفصلة للقاطرات/العربات، فرامل واقعية، تحسين الطرق ذات الاتجاه الواحد، أمان التقاطعات، إلخ؛
- **نواة OpenTTD 16.0**: توافق كامل مع نظام NewGRF/البرامج النصية/الحفظ البيئي.
