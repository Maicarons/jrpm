# سرعة سير الطائرة قابلة للتعديل

مأخوذ من **embeddedt/OpenTTD-modded** (الدفعة الأولى من النقل).

## الوظيفة

إضافة إعداد لعبة جديد **`vehicle.plane_taxi_speed` (سرعة سير الطائرة)**، يمكن ضبط الحد الأقصى لسرعة سير الطائرة على أرض المطار بشكل مستقل:

- النطاق **1–8**، الافتراضي **4** (= حد السير الأصلي 50 وحدة)
- كلما زادت القيمة، زادت سرعة السير (1 → 12.5، 8 → 100)
- يعمل **بشكل مستقل** عن إعدادات سرعة الطائرة الأخرى (`plane_speed` المضاعف العام)، لا يتداخل معها

## موقع الإعداد

داخل اللعبة **الإعدادات → الإعدادات المتقدمة → المركبات (Vehicles)**، أو في ملف التكوين `openttd.cfg`:

```ini
[vehicle]
plane_taxi_speed = 4
```

## ملاحظات التنفيذ

- الإعداد مع `SettingFlag::NoNetwork` (سلطة الخادم، عند الاتصال عبر الشبكة يقرره مضيف الغرفة)
- يستخدم **بوابة ميزة XSLF الموسعة** (`XSLFI_PLANE_TAXI_SPEED`، الإصدار 1): عند تحميل الحفظ القديم، هذه الميزة غير موجودة ← يبقى الإعداد على القيمة الافتراضية 4، **لا يفسد أي حفظ قديم**
- يتم تطبيق حد سرعة السير عندما تكون حالة الطائرة `AS_RUNNING` (السير على الأرض)، ويكون `min(حد سرعة الطراز, حد سرعة السير)`

## الملفات المعنية

- `src/aircraft_cmd.cpp` (إضافة ثابت `SPEED_LIMIT_TAXI` + منطق حد سرعة السير)
- `src/table/settings/game_settings.ini` (تعريف الإعداد)
- `src/settings_type.h` (`VehicleSettings::plane_taxi_speed`)
- `src/sl/extended_ver_sl.h/.cpp` (تسجيل ميزة XSLF)
- `src/lang/english.txt` (STR_CONFIG_SETTING_PLANE_TAXI_SPEED*)
