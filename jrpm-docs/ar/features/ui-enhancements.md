# تحسين واجهة المستخدم عبر الشبكة

الدفعة الثانية من النقل من **citymania-org/cmclient**، تم تنفيذها كـ **أوامر كونسول** (لا تعتمد على البنية التحتية للمفاتيح الساخنة/شريط الأدوات في cmclient، مستقرة وقابلة للبرمجة النصية).

## الإشارات المرجعية للموقع (Viewport Locations)

حفظ/استعادة موقع viewport الرئيسي ومستوى التكبير (9 فتحات)، مناسبة للتنقل السريع بين مصانعك ومحطاتك ومناطق المنافسين عند اللعب عبر الشبكة.

```
savelocation <1-9>    # حفظ موقع viewport الحالي + مستوى التكبير
gotolocation <1-9>    # الانتقال إلى الموقع المحفوظ
```

## تفاصيل شحن الشركة (Company Cargo Details)

نافذة إحصاءات تسرد **كمية البضائع المسلمة + الإيرادات** للشركة حسب نوع البضاعة، يمكن التبديل بين فترتي **الإجمالي / الشهر الماضي**.

```
company_cargo <company_id>    # فتح نافذة تفاصيل الشحن
```

- تسرد النافذة كمية كل بضاعة قياسية وإيراداتها + إجمالي في الأسفل (مطابق تماماً لـ cmclient)
- النقر على رأس الجدول "Cargo" يبدّل بين الإجمالي/فترة الشهر الماضي
- يتم تتبع إيرادات كل بضاعة عبر `CompanyEconomyEntry::cargo_income` (امتداد حفظ `XSLFI_COMPANY_CARGO_INCOME`)، الحفظ والقراءة دون فقدان

## مساعدة المشاهدة (Watch)

يساعد المراقبين على الانتقال السريع إلى منطقة البناء لشركة معينة (الانتقال إلى آخر إحداثيات بناء لتلك الشركة).

```
watch <company_id>    # انتقال viewport إلى موقع الشركة
```

## العناصر التي تم تخطيها والأسباب

| وظيفة cmclient | معالجة jrpm |
|---|---|
| طبقة قائمة اللاعبين العائمة (cm_client_list_gui) | jgrpp **لديه بالفعل** نافذة اللاعبين عبر الإنترنت (`NetworkClientList`)، لا حاجة لتنفيذ مكرر |
| تلميحات تفاصيل الأرض (cm_tooltips) | نافذة LandInfoWindow في jrpm **تغطي بالفعل** عرض تفاصيل المنازل/الصناعات/المحطات |
