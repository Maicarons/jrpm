# مقدمة عن OpenTTD-JRPM

## ما هو

**OpenTTD-JRPM (jrpm)** هو فرع تطوير ثانوي يعتمد على [Patchpack JGR](https://github.com/JGRennison/OpenTTD-patches) (jgrpp)، يدمج ميزات "فك القاطرة" و"المطار المعياري" من [pulsexlb/OpenTTD-patches](https://github.com/pulsexlb/OpenTTD-patches)، ويضيف وظائف حصرية لـ jrpm. الإصدار الحالي: **jrpm-0.1.0**.

إنه إصدار جديد قابل للتثبيت بشكل مستقل والتواصل عبر الشبكة بشكل مستقل: يستخدم عميل/خادم jrpm معرف إصدار مستقل (`jrpm-0.1.0`) للمصافحة، معزول تماماً عن إصدارات jgrpp الأصلي و pulsexlb، لتجنب الارتباك في الإصدارات.

## نظرة سريعة على الميزات

### من pulsexlb (152 commit، مدمجة عبر git merge)
- **فك القاطرة (decouple)** : نظام كامل لفصل/ربط القطارات——أوامر الفك، نقل العلامات، حدود طول الربط وسرعته، دعم قاطرتين، ربط NewGRF، توجيه الربط (YAPF/NPF)، جدولة مستقلة بعد الفك؛
- **المطار المعياري (multitile-airport)** : إعادة هيكلة نظام المطار متعدد البلاطات——نظام أنواع air (`air.h`/`air_type.h`/`newgrf_airtype.*`)، جدولة PBS الجوية (`pbs_air.*`)، توجيه YAPF الجوي، تخطيط مطار قابل للتعديل `station.allow_modify_airports`، نوع الطيران الافتراضي `gui.default_air_type`.

### حصري لـ jrpm
| الوظيفة | الوصف | المدخل |
|---|---|---|
| تنزيل الموارد: مرايا متعددة + متوازي | مرايا متعددة مفصولة بفواصل، تنزيل متوازي على مستوى الملف (عدد متزامن قابل للتكوين)، تبديل المرايا تلقائياً عند الفشل | الإعدادات → `network.content_mirrors` / `network.content_download_parallel` |
| التجميع التلقائي للمركبات | تجميع/إعادة تجميع تلقائي بنقرة واحدة حسب الطلبات/الجدول الزمني المشترك، اسم مجموعة يُؤخذ تلقائياً من اسم الخط | زر نافذة التجميع / أمر الكونسول `autogroup` |
| تلميح سعر البناء | عند بناء السكك الحديدية/الطرق/التضاريس، يعرض تلميح سعر التكلفة التقديرية في الوقت الفعلي فوق الماوس | شريط أدوات السكك/الطرق/التضاريس |
| ذكاء اصطناعي يدرك اللعبة بأكملها | يحافظ على NoAI، ويضيف واجهة برمجة تطبيقات `AIGlobal` الشاملة + ذكاء اصطناعي نموذجي GlobalAI، مع تحكم في الوصول عبر إعدادات اللعبة | `game.script.allow_global_ai_access` |
| توافق إصدارات متعددة للخادم | خادم jrpm يقبل عملاء jrpm / jgrpp الأصلي / pulsexlb في نفس الوقت | تفعيل تلقائي عند فحص الانضمام للخادم |

### الوراثة الكاملة
- جميع ميزات jgrpp (إشارات محسّنة، جدولة مجدولة، tracerestrict، استبدال القوالب، إلخ)؛
- توافق كامل مع وظائف OpenTTD الأساسية ونظام NewGRF/البرامج النصية البيئي.
