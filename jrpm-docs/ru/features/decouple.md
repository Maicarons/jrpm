# Смена локомотивов (decouple)

> Источник: ветка функций `jgrpp-decouple` из pulsexlb/OpenTTD-patches (ядро из 152 коммитов), объединено через git merge в jrpm.

## Краткое описание функции

«Смена локомотивов» позволяет поездам **расцепляться и сцепляться** с вагонами или локомотивами на станциях/в депо, обеспечивая:

- **Расцепление**: поезд по «приказу на расцепку» оставляет часть вагонов (или вагоны+локомотив) на указанной станции, остальная часть продолжает движение;
- **Сцепление**: поезд ожидает на станции и автоматически сцепляется с другим составом (или стоящей группой вагонов);
- **После расцепления оба поезда выполняют свои собственные расписания**: через механизм «условного пропуска команд» и т.п. два поезда после расцепления следуют разным расписаниям;
- **Передача маршрутных листов**: при расцепке/сцепке маршрутные листы (теги ограничения отслеживания) правильно передаются или дедублицируются.

## Ключевые возможности

| Возможность | Описание |
|---|---|
| Приказы на расцепку/сцепку | Новые типы приказов с поддержкой «загрузить/не загружать», «ожидать сцепки», «расцепить» и других ограничений |
| Ограничения длины сцепки и скорости | Операция сцепки ограничена по длине поезда; сцепка имеет ограничение скорости |
| Поддержка двойной тяги | Правильная сцепка/расцепка переднего и заднего локомотивов (включая NewGRF двухголовые локомотивы) |
| Навигация сцепки | YAPF/NPF поддерживают планирование пути сцепки; сцепка только на станциях |
| Движение задним ходом | После сцепки возможно движение задним ходом, поддержка тактики «расцепиться и ехать назад» |
| Сцепка NewGRF | Поддержка атрибутов сцепки, определённых NewGRF (атрибуты 0xC6/0xF2 и т.д.) |
| Сохранение | Версия сохранения `SLV_ORDER_DECOUPLE`; сохранение счётчика `num_decouple` |

## Способ использования

1. На станции используйте приказ «расцепить» (`decouple`) для разделения поезда;
2. Установите приказ на сцепку, чтобы поезд ожидал соединения;
3. В сочетании с «условным пропуском команд» (conditional order skip) два поезда после расцепки следуют разным маршрутам;
4. На станции можно перетаскивать вагоны для изменения порядка или использовать вспомогательные инструменты типа «фильтр по длине».

## Примечания

- Эта функция включает глубокие изменения физического порядка поезда/логики резервирования сигналов, **рекомендуется тщательное регрессионное тестирование после сборки на реальном железе**: расцепка, сцепка, задний ход, восстановление после столкновения, автозамена (autoreplace) и т.д.;
- Связанные строки и GUI для расцепки уже включены (`STR_DECOUPLE*` и т.д.).
