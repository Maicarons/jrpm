# Регулируемая скорость руления самолётов

Происходит из **embeddedt/OpenTTD-modded** (первая партия портирования).

## Функция

Новая настройка игры **`vehicle.plane_taxi_speed` (скорость руления самолётов)** позволяет независимо регулировать ограничение скорости самолётов при рулении по земле в аэропорту:

- Диапазон **1–8**, по умолчанию **4** (= оригинальное ограничение руления 50 единиц)
- Чем больше значение, тем быстрее руление (1 → 12.5, 8 → 100)
- Действует **независимо** от других настроек скорости самолётов (`plane_speed` глобальный множитель), не влияет на них

## Расположение настройки

В игре: **Настройки → Экспертные настройки → Транспортные средства (Vehicles)**, или в файле конфигурации `openttd.cfg`:

```ini
[vehicle]
plane_taxi_speed = 4
```

## Особенности реализации

- Настройка с `SettingFlag::NoNetwork` (серверная, в многопользовательской игре определяется хостом)
- Использует **XSLF-расширение** (`XSLFI_PLANE_TAXI_SPEED`, версия 1): при загрузке старых сохранений эта функция отсутствует → настройка остаётся со значением по умолчанию 4, **не нарушая никакие старые сохранения**
- Ограничение скорости руления применяется, когда самолёт в состоянии `AS_RUNNING` (руление по земле), берётся `min(ограничение модели, ограничение руления)`
