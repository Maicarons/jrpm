# Обзор возможностей

jrpm = все возможности jgrpp + pulsexlb (смена локомотивов + модульные аэропорты) + modded (история поездок + скорость руления) + заимствования из cmclient (улучшения UI) + собственные функции jrpm.

## Собственные функции jrpm

| # | Функция | Документация | Статус |
|---|---|---|---|
| 1 | Загрузка ресурсов: несколько зеркал + параллельно | [Загрузка ресурсов](./01-resource-download) | ✅ Реализовано (настраиваемое количество) |
| 2 | Исследование лимитов сервера | [Лимиты сервера](./02-server-caps) | 📖 Выводы исследования (структурные ограничения) |
| 3 | Автоматическая группировка ТС | [Автоматическая группировка ТС](./03-vehicle-autogroup) | ✅ Реализовано |
| 4 | Глобальный AI | [Глобальный AI](./05-global-ai) | ✅ Реализовано |

> Примечание: бывший F4 «Подсказка стоимости строительства» удалён по требованию (коммит `96ebfb75`).

## Полное наследование

- **Все возможности jgrpp**: улучшенные сигналы (множественные/программируемые/слоты и счётчики), scheduled dispatch, tracerestrict, шаблонная замена, раздельные окна покупки локомотивов/вагонов, реалистичное торможение, улучшенные односторонние дороги, безопасные переезды и т.д.;
- **Ядро OpenTTD 16.0**: полная совместимость с экосистемой NewGRF/скриптов/сохранений.

## Быстрый поиск настроек

| Функция | Настройка |
|---|---|
| Количество параллельных загрузок | `network.content_download_parallel` (1-8) |
| Список зеркал загрузки | `network.content_mirrors` |
| Сервер контента | `network.content_server` |
| Изменение планировки аэропортов | `station.allow_modify_airports` |
| Тип авиации по умолчанию | `gui.default_air_type` |
| Включение глобального AI | `game.script.allow_global_ai_access` |
| Скорость руления самолётов | `vehicle.plane_taxi_speed` (1-8, по умолч. 4) |

## Быстрый поиск консольных команд

| Функция | Команда |
|---|---|
| Автоматическая группировка ТС | `autogroup train\|road\|ship\|aircraft` |
| Добавить глобальный AI | `start_ai GlobalAI` |
| Закладки позиций | `savelocation <1-9>` / `gotolocation <1-9>` |
| Детализация грузов компании | `company_cargo <company_id>` |
| Наблюдение за компанией | `watch <company_id>` |
| Копирование/поворот/сохранение/загрузка/восстановление чертежа | `blueprint_copy` / `blueprint_rotate` / `blueprint_save <0-15>` / `blueprint_load <0-15>` / `blueprint_build` |
| Запись/воспроизведение команд | `cmdrecord [start [file]]` / `cmdrecord stop` / `cmdreplay <file>` |
| Скорость игры/статистика/экспорт/посадка деревьев | `cmgamespeed [n]` / `cmgamestats` / `cmexport` / `cmtreemap <file>`
