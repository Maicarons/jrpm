## মাল্টিপ্লেয়ার নীতি ("নতুন সংস্করণ সহজে মাল্টিপ্লেয়ার")

- jrpm একটি **tagged সংস্করণ**: `IsNetworkCompatibleVersion` রিভিশন স্ট্রিং সম্পূর্ণ মিল প্রয়োজন → **jrpm ক্লায়েন্ট শুধু jrpm সার্ভারের সাথে মাল্টিপ্লেয়ার করে**, jgrpp 0.73.x / pxp থেকে সম্পূর্ণ বিচ্ছিন্ন;
- **সার্ভার শিথিলতা**: jrpm সার্ভার অতিরিক্তভাবে `jgrpp-*` ও `pxp*` ক্লায়েন্ট গ্রহণ করে (`IsJgrppNativeNetworkRevision` / `IsPxpNetworkRevision`, NewGRF সংস্করণ অবশ্যই মিলতে হবে);
- তাই: jrpm সার্ভার হোস্ট খোলা = শুধু jrpm প্লেয়ার গ্রহণ (ডিফল্ট); পুরনো ক্লায়েন্টের সাথে সামঞ্জস্য প্রয়োজন হলে কনফিগারেশন পরিবর্তন ছাড়াই jgrpp/pxp প্লেয়ার গ্রহণ করা যায়।

## বিল্ড ও যাচাইকরণ (ব্যবহারকারীর নিজস্ব মেশিনে নির্বাহ)

```bash
# প্রথমবার (CMake + নির্ভরতা প্রয়োজন, COMPILING.md দেখুন)
cmake -B build ..
cmake --build build -j
# আউটপুট: build/openttd-jrpm.exe
```

যাচাইকরণ অগ্রাধিকার:
১. `openttd-jrpm -v` দেখায় `jrpm-0.1.0`;
২. একক খেলা শুরু করে ১-২ বছর চালান (মার্জ train/airport বড় পরিবর্তন ও存档 সংস্করণ allow_modify_airports ইত্যাদি নতুন কারণে bump হতে পারে);
৩. সার্ভার খোলার পর: jrpm ক্লায়েন্ট যোগ ✓; মূল jgrpp 0.73.x ক্লায়েন্ট যোগ করার চেষ্টা (প্রত্যাশিত: যোগ দিতে পারবে, NewGRF সামঞ্জস্যপূর্ণ হলে);
৪. ট্রেন ডিকাপলিং: ট্রেনে ডিকাপল/অ্যাটাচ অর্ডার যোগ করুন, ডিকাপলের পর দুই ট্রেন স্বাধীন রুটিং যাচাই করুন; মডুলার এয়ারপোর্ট: `station.allow_modify_airports` চালু করে এয়ারপোর্ট লেআউট পরিবর্তন করুন;
৫. পূর্ববর্তী ৫টি বৈশিষ্ট্য রিগ্রেশন (সমান্তরাল ডাউনলোড, স্বয়ংক্রিয় গ্রুপিং, নির্মাণ টুলটিপ, GlobalAI)।
