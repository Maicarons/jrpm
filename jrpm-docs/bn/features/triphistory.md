# যানবাহন ট্রিপ ইতিহাস (Trip History)

উৎস **embeddedt/OpenTTD-modded** (প্রথম ব্যাচ পোর্ট), jrpm-এর নতুন স্ট্রিং ও তারিখ API-তে অভিযোজিত।

## বৈশিষ্ট্য

প্রতিটি যানবাহন সর্বশেষ **১০টি ট্রিপ**-এর ডেটা মনে রাখে, যানবাহন বিবরণ উইন্ডোতে নতুন **History (ইতিহাস)** বাটনে দেখা যায়:

| কলাম | অর্থ |
|---|---|
| Received (পৌঁছানো) | এই ট্রিপে কার্গো পাওয়ার তারিখ |
| Profit (লাভ) | এই ট্রিপের লাভ (ঋণাত্মক হলে হলুদ দেখায়) |
| % Change | পূর্ববর্তী ট্রিপের তুলনায় লাভের পরিবর্তনের শতাংশ (সবুজ + / লাল -) |
| TBT | পূর্ববর্তী ট্রিপের সাথে সময়ের ব্যবধান (দিন) |
| Change | পূর্ববর্তী ট্রিপের তুলনায় সময়ের পরিবর্তন (দিন) |
| Occupancy | এই ট্রিপের গড় যাত্রী/কার্গো পূর্ণতার হার (%) |

উইন্ডোর নিচে আরও সারসংক্ষেপ পরিসংখ্যান:

- **Total income for the last N trips**: N ট্রিপের মোট লাভ + প্রতি ট্রিপের দৈনিক গড় লাভ
- **Average trip length**: গড় ট্রিপ ব্যবধান (দিন)
- **Improvement over last N trips**: লাভের সমন্বিত পরিবর্তনের শতাংশ

## রেকর্ডিং মেকানিজম

- **AddValue**: যানবাহন একটি ট্রিপ সম্পূর্ণ করলে (`CargoPayment` ডিস্ট্রাক্টর) লাভ, তারিখ, পূর্ণতার হার, স্টেশনের মধ্যে দূরত্ব রেকর্ড করে
- **NewRound**: যানবাহন সময়সূচী অনুযায়ী প্রথম গন্তব্যে পৌঁছালে নতুন ট্রিপ শুরু হয়
- **পূর্ণতার হার**: যানবাহন স্টেশন ছেড়ে যাওয়ার সময় সংগ্রহ করা হয় (jrpm-এর বিদ্যমান `trip_occupancy` মেকানিজম পুনঃব্যবহার)

## বাস্তবায়ন ব্যাখ্যা

- ডেটা **NOSAVE** (শুধু রানটাইম,存档 এ লেখে না), তাই存档 সংস্করণ বাড়ানোর প্রয়োজন নেই, পুরনো存档 সম্পূর্ণ সামঞ্জস্যপূর্ণ
- নতুন উইন্ডো ক্লাস `WindowClass::VehicleTripHistory`, উইন্ডো ID যানবাহন ID
- যানবাহন বিবরণ উইন্ডো (ট্রেন/অ-ট্রেন) শিরোনাম বারে History বাটন যোগ করা হয়েছে
- যানবাহন মুছে ফেলা হলে ইতিহাস উইন্ডো স্বয়ংক্রিয়ভাবে বন্ধ হয়
