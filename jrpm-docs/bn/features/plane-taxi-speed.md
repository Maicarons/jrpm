# বিমান ট্যাক্সি গতি সামঞ্জস্যযোগ্য

উৎস **embeddedt/OpenTTD-modded** (প্রথম ব্যাচ পোর্ট)।

## বৈশিষ্ট্য

নতুন গেম সেটিংস **`vehicle.plane_taxi_speed` (বিমান ট্যাক্সি গতি)**, বিমানের এয়ারপোর্টে ভূমিতে ট্যাক্সি করার সময় গতি সীমা স্বাধীনভাবে সামঞ্জস্য করা যায়:

- পরিসীমা **১–৮**, ডিফল্ট **৪** (= মূল সংস্করণের ৫০ ইউনিট ট্যাক্সি গতি সীমা)
- মান যত বড়, ট্যাক্সি তত দ্রুত (১ → ১২.৫, ৮ → ১০০)
- অন্যান্য বিমান গতি সেটিংস (`plane_speed` গ্লোবাল মাল্টিপ্লায়ার) থেকে **স্বাধীনভাবে কার্যকর**, পারস্পরিক হস্তক্ষেপ নেই

## সেটিংস অবস্থান

গেমের ভিতরে **সেটিংস → এক্সপার্ট সেটিংস → যানবাহন (Vehicles)**, অথবা কনফিগারেশন ফাইল `openttd.cfg`:

```ini
[vehicle]
plane_taxi_speed = 4
```

## বাস্তবায়ন ব্যাখ্যা

- সেটিংস `SettingFlag::NoNetwork` সহ (সার্ভার কর্তৃত্বপূর্ণ, মাল্টিপ্লেয়ারে হোস্ট নির্ধারণ করে)
- **XSLF এক্সটেনশন বৈশিষ্ট্য গেট** ব্যবহার করে (`XSLFI_PLANE_TAXI_SPEED`, সংস্করণ ১): পুরনো存档 লোড করার সময় এই বৈশিষ্ট্য নেই → সেটিংস ডিফল্ট মান ৪-এ থাকে, **কোনো পুরনো存档 নষ্ট করে না**
- ট্যাক্সি গতি সীমা বিমানের অবস্থা `AS_RUNNING` (ভূমিতে ট্যাক্সি) হলে প্রয়োগ করা হয়, `min(বিমানের ধরনের গতি সীমা, ট্যাক্সি গতি সীমা)` নেওয়া হয়
