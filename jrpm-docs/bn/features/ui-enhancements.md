# মাল্টিপ্লেয়ার UI উন্নতি

দ্বিতীয় ব্যাচ **citymania-org/cmclient** থেকে পোর্ট করা, **কনসোল কমান্ড** আকারে বাস্তবায়িত (cmclient-এর হটকি/টুলবার পরিকাঠামোর উপর নির্ভরশীল নয়, স্থিতিশীল ও স্ক্রিপ্টযোগ্য)।

## লোকেশন বুকমার্ক (Viewport Locations)

প্রধান ভিউপোর্টের অবস্থান ও জুম সংরক্ষণ/পুনরুদ্ধার (৯টি স্লট), মাল্টিপ্লেয়ারে নিজের কারখানা, স্টেশন ও প্রতিপক্ষের এলাকায় দ্রুত যাওয়ার জন্য উপযোগী।

```
savelocation <1-9>    # বর্তমান ভিউপোর্ট অবস্থান+জুম সংরক্ষণ
gotolocation <1-9>    # সংরক্ষিত অবস্থানে যান
```

## কোম্পানি কার্গো বিবরণী (Company Cargo Details)

প্রতি কার্গো অনুযায়ী কোম্পানির **পাঠানো পরিমাণ + আয়**-এর পরিসংখ্যান উইন্ডো, **মোট / গত মাস** দুটি সময়কালের মধ্যে সুইচ করা যায়।

```
company_cargo <company_id>    # কার্গো বিবরণী উইন্ডো খুলুন
```

- উইন্ডো প্রতিটি স্ট্যান্ডার্ড কার্গোর পরিমাণ, আয় + নিচে মোট তালিকা (cmclient-এর সাথে সম্পূর্ণ সামঞ্জস্যপূর্ণ)
- হেডার "Cargo" ক্লিক করে মোট/গত মাস সুইচ
- প্রতি কার্গো আয় `CompanyEconomyEntry::cargo_income`-এর মাধ্যমে ট্র্যাক করা হয় (`XSLFI_COMPANY_CARGO_INCOME`存档 এক্সটেনশন),存档 রাউন্ড-ট্রিপ ক্ষতিহীন

## দর্শন সহায়তা (Watch)

দর্শক দ্রুত একটি কোম্পানির নির্মাণ এলাকায় অবস্থান করতে পারে (কোম্পানির সর্বশেষ নির্মাণের স্থানাঙ্কে যান)।

```
watch <company_id>    # ভিউপোর্ট কোম্পানির অবস্থানে যান
```

## বাদ দেওয়া আইটেম ও কারণ

| cmclient বৈশিষ্ট্য | jrpm-এ ব্যবস্থাপনা |
|---|---|
| প্লেয়ার তালিকা ওভারলে (cm_client_list_gui) | jgrpp-এ **ইতিমধ্যে** Online Players উইন্ডো আছে (`NetworkClientList`), পুনরায় বাস্তবায়নের প্রয়োজন নেই |
| ভূমি বিবরণ টুলটিপ (cm_tooltips) | jrpm-এর LandInfoWindow **ইতিমধ্যে** বাড়ি/শিল্প/স্টেশন বিবরণ প্রদর্শন কভার করে |
