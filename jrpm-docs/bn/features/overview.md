# বৈশিষ্ট্য তালিকা

jrpm = jgrpp সম্পূর্ণ বৈশিষ্ট্য + pulsexlb (ট্রেন ডিকাপলিং + মডুলার এয়ারপোর্ট) + modded (ট্রিপ ইতিহাস + ট্যাক্সি গতি) + cmclient অনুকরণ (মাল্টিপ্লেয়ার UI উন্নতি) + jrpm নিজস্ব বৈশিষ্ট্য।

## সম্পূর্ণ উত্তরাধিকার

- **jgrpp-এর সব বৈশিষ্ট্য**: সিগন্যাল উন্নতি (মাল্টিপল সিগন্যাল/প্রোগ্রামেবল সিগন্যাল/স্লট ও কাউন্টার), শিডিউল্ড ডিসপ্যাচ, ট্রেসরেস্ট্রিক্ট, টেমপ্লেট প্রতিস্থাপন, লোকো/ওয়াগন পৃথক ক্রয় উইন্ডো, রিয়ালিস্টিক ব্রেকিং, ওয়ান-ওয়ে রোড উন্নতি, লেভেল ক্রসিং নিরাপত্তা ইত্যাদি;
- **OpenTTD 16.0 কার্নেল**: NewGRF/স্ক্রিপ্ট/存档 ইকোসিস্টেম সম্পূর্ণ সামঞ্জস্যপূর্ণ।

| ডিফল্ট এয়ার টাইপ | `gui.default_air_type` |
